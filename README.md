# Wildlands — стартовий проєкт

Це перша робоча основа онлайн-гри з видом зверху:
- Node.js + Express + Socket.IO;
- SQLite для облікових записів гравців, позицій та стану ресурсів;
- процедурна карта з біомами;
- рух гравця, чат, збирання деревини/каменю/ягід;
- мобільне керування та камера;
- сервер перевіряє рух і збір ресурсів.

## Запуск локально

Потрібен Node.js 20 або новіший.

```bash
npm install
npm start
```

Відкрий `http://localhost:3000`.

## Деплой на Render

1. Створи новий GitHub-репозиторій і завантаж сюди всі файли.
2. У Render створи **New → Web Service** та під'єднай репозиторій.
3. Build Command: `npm install`
4. Start Command: `npm start`
5. Render автоматично встановить змінну `PORT`.

### Важливо про SQLite і Render

Безкоштовний Render Web Service може засинати, а його файлове сховище не є постійним. SQLite-файл може зникнути після перезапуску/деплою. Для справжнього постійного прогресу під'єднай Persistent Disk (якщо доступний на твоєму тарифі) з mount path `/var/data`, або згодом перенесемо базу на керований PostgreSQL.

Якщо `DATABASE_PATH` не заданий, сервер використовує:
- `/var/data/wildlands.db`, коли існує `/var/data`;
- інакше `./data/wildlands.db`.

## Файли

- `server.js` — сервер, API, Socket.IO, SQLite.
- `public/index.html` — сторінка гри.
- `public/style.css` — інтерфейс.
- `public/game.js` — карта, рендеринг, керування.

## Поточні межі прототипу

Це фундамент, а не фінальна гра. Світ зараз є нескінченним полем чанків із повторюваною процедурною генерацією, але клієнт малює найближчу область. Ресурси синхронізуються сервером. Поселення, NPC-професії, дипломатія, печери, повний крафт, 3D та складні біоми — наступні етапи.

Не публікуй секретні ключі або паролі в коді. Для майбутньої модерації та адміністрування додамо окрему захищену систему.
